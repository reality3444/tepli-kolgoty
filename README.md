# Сайт для Vercel

1. Імпортуйте цю папку як проєкт у Vercel. Для Framework Preset виберіть Other.
2. У Project Settings → Environment Variables додайте `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`. Значення беруться з ваших налаштувань Telegram; токен не додавайте у файли сайту або Git.
3. Застосуйте змінні до потрібних середовищ (Production і, за потреби, Preview) та створіть новий deployment. Зміна змінних не оновлює старі деплої автоматично.
4. Перевірте, що бот доданий до групи й може надсилати повідомлення. Зробіть тестову заявку та переконайтесь, що вона надійшла.

Статичні сторінки доступні у корені, серверна функція `api/order.mjs` надсилає заявки через Telegram. Потрібен вихідний доступ функції до Telegram API. Не додавайте `.env` у репозиторій.
